## Architecture

I prefer systems that are:

**Simple → Modular → Reusable → Extendable**

Instead of creating large frameworks with tightly coupled systems, I prefer keeping packages small and focused.

```text
Game
│
├── Core
│
├── Assets
│
├── Audio
│
├── UI
│
├── Data Config
│
├── Data Save
│
└── Features
    ├── Daily Reward
    ├── Spin
    ├── Battle Pass
    ├── Rank
    └── Tutorial
```

Each module should have a clear responsibility and minimal dependencies.
